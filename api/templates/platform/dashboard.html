How the live pipeline works

  1. Image → 180×180 → Xception softmax (frozen ImageNet backbone).
  2. Argmax class → scientific name in VNPlant-200.
  3. Name joined to medicinal + soil + fertilizer + IPM tables.
  4. Optional pH / NPK / moisture compared with target bands.

Chemistry on screen is literature text, not HPLC. Soil bands are heuristics until you replace them with plot data.
